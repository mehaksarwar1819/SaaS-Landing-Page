# NeuroFlow AI - SaaS Landing Page

## Project Overview

NeuroFlow AI is a modern, responsive SaaS Landing Page built using Tailwind CSS. The project demonstrates responsive web design, reusable UI components, clean layouts, and modern frontend design principles. It was developed as the Final Assignment for the TechTide Summer Internship 2026 Tailwind CSS module.

---

## Project Theme

**AI SaaS Platform**

NeuroFlow AI helps businesses automate workflows, analyze data, improve productivity, and collaborate efficiently using Artificial Intelligence.

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
4. No installation or build process is required because Tailwind CSS is loaded through the CDN.
